A VS Code extension lives at [UnifiedMozaic/vscode-extension](https://github.com/UnifiedMozaic/vscode-extension). It provides syntax highlighting, type checking on save, and build and run with F5.

Install the `.vsix` from its [releases](https://github.com/UnifiedMozaic/vscode-extension/releases) and set `unifiedmozaic.compilerPath` to the cloned UnifiedMozaic repository.

```sh
code --install-extension unifiedmozaic-0.1.0.vsix
```
